# HC Česká Lípa

Frontend homepage concept – Gulp 4, Twig, SCSS, Bootstrap 5.

## Development

`npm install` and then use the project's Gulp build. Source homepage is `src/layouts/01.0_homepage.twig`.

## Preview

Open `build/01.0_homepage.html`. The built preview includes `css/hc-home.css` and `js/hc-home.js` for immediate viewing without installing dependencies.

## Design notes

- Responsive white/red homepage, left logo area and right-side navigation.
- Two A-team match cards and adjacent compact league table.
- Youth categories, news, partners, no YouTube or Bleskovky.
- Club crest treatment is a temporary typographic placeholder until approved logo artwork is supplied.
- Editorial photos are temporary illustrative third-party images.
- Standings are placeholders and must be populated from an official feed before release.
